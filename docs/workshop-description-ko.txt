[h1]PZ AI Translation Generator[/h1]

[b]Project Zomboid Build 42.20.x+용 AI 모드 번역팩 생성기[/b]

이 모드는 활성 모드 전체를 다시 번역하지 않습니다!

원본 모드나 현재 사용 중인 다른 번역팩이 이미 번역을 제공하는 항목은 제외하고, 어디에도 번역이 없는 항목만 사용자가 선택한 AI API로 보냅니다.

완성된 번역은 원본과 분리된 로컬 모드 [b]PZAITranslationGenerated[/b]로 만들어집니다.

[b]지원 AI 서비스[/b]
Gemini · DeepL · OpenAI · Claude · DeepSeek · Yandex · OpenAI-compatible

[h2]주요 특징[/h2]
[list]
[*][b]없는 번역만 처리[/b] — 이미 번역된 내용은 건너뜁니다.
[*][b]기존 번역 보존[/b] — 원본 모드와 사용 중인 번역팩을 우선합니다.
[*][b]모드별 선택[/b] — 필요한 모드만 직접 선택합니다.
[*][b]중단 및 재개[/b] — 이미 끝난 번역을 남겨두고 나머지만 이어갑니다.
[*][b]검토 및 수정[/b] — 게임 안에서 생성된 번역을 고칠 수 있습니다.
[*][b]충돌 보호[/b] — 여러 모드의 번역이 충돌하면 아무 값이나 덮어쓰지 않습니다.
[*][b]원본 보호[/b] — Workshop 모드와 게임 파일은 수정하지 않습니다.
[/list]

Helper ZIP에는 실행 환경이 포함되어 있어 [b]Node.js를 따로 설치할 필요가 없습니다.[/b] Helper와 API Key는 Steam Workshop 모드에 포함되지 않습니다.

[h2]실제 사용 순서[/h2]

[h3]1. 최초 1회 설정과 첫 번역[/h3]
[olist]
[*]이 모드를 구독하고 [b]PZ AI Translation Generator[/b]를 활성화합니다.
[*]위 링크에서 Helper ZIP을 받아 Steam 및 Program Files 외부 폴더에 압축 해제합니다.
[*][b]START-TranslationHelper.vbs[/b]를 실행합니다.
[*][b]Options > Mods > PZ AI 번역팩 생성기[/b]에서 AI 서비스, 모델, API Key, 번역 언어를 설정하고 [b]Apply[/b]를 누릅니다.
[*]캐릭터 정보 창의 [b]AI Translation Generator[/b] 탭에서 [b]Test API: Hello, World![/b]로 연결을 확인합니다.
[*][b]Manage translation targets[/b]에서 번역할 모드를 선택하고 저장합니다.
[*]첫 작업은 [b]Start new translation[/b]을 한 번 누릅니다.
[*][b]Complete[/b]가 표시되면 [b]PZAITranslationGenerated[/b]를 활성화합니다.
[*]메인 화면으로 나간 뒤 월드에 다시 입장합니다. 반영되지 않으면 게임을 재시작합니다.
[/olist]

[h3]2. 이후 작업은 Resume 사용[/h3]

최초 번역 이후에는 보통 [b]Start new translation을 다시 누를 필요가 없습니다.[/b]

Helper를 실행하고 필요하면 번역 대상이나 AI 설정을 바꾼 뒤 [b]Resume interrupted translation[/b]을 누르십시오. 이미 끝난 번역과 저장 기록을 먼저 사용하고 [b]아직 번역되지 않은 항목만[/b] 처리합니다.

Pause 후 재개, 게임이나 Helper 종료 후 재개, 새 모드 추가, AI 서비스 또는 모델 변경, HTTP 429 / 456 이후에도 Resume을 사용합니다.

[b]참고:[/b] 무료 API의 요청 제한을 보호하기 위해 요청 사이에 기본 [b]70초 대기[/b]가 적용될 수 있습니다. 번역 중에도 게임을 플레이할 수 있으며 Helper는 뒤에서 계속 작업합니다.

[h2]번역 검토 및 수정[/h2]

[b]Options > Mods > PZ AI 번역팩 생성기 > Quality tools[/b]에서 생성된 번역을 확인하고 수정할 수 있습니다.

[list]
[*][b]Review generated translations[/b] — 항목별 확인 및 수정
[*][b]Bulk correct translations[/b] — 반복되는 오역을 Preview 후 일괄 수정
[*][b]Confirm all N[/b] — 전체 N개 항목 적용을 한 번 더 확인
[*][b]Review hardcoded Lua strings[/b] — Lua 코드에 직접 적힌 문장 후보 확인
[/list]

하드코딩 문장 검사는 원본 파일을 수정하거나 문장을 자동으로 API에 보내지 않습니다. 이런 문장은 별도 호환 패치가 필요할 수 있습니다.

[h2]자주 묻는 질문 (Q&A)[/h2]

[h3]Q. Translation Helper는 안전한가요?[/h3]

Helper의 동작 코드는 ZIP 안의 VBS, PowerShell, JavaScript 파일로 확인할 수 있습니다.

[list]
[*][b]별도 Node.js 설치 불필요[/b] — 공식 Node.js LTS Windows x64 런타임을 포함합니다.
[*][b]npm 외부 패키지 없음[/b] — Node 기본 기능만 사용합니다.
[*][b]원본 보호[/b] — 원본 모드를 수정하지 않습니다.
[*][b]불필요한 통신 없음[/b] — 자동 업데이트와 사용 통계 전송 기능이 없습니다.
[*][b]파일 확인 가능[/b] — ZIP SHA-256과 내부 [b]SHA256SUMS.txt[/b]를 제공합니다.
[/list]

현재 베타에는 [b]Windows 개발자 서명이 적용되어 있지 않습니다.[/b] 따라서 SmartScreen이나 백신 경고가 표시될 수 있습니다.

API Key는 사용자 PC에 저장됩니다. 가능하면 사용량 제한이 있는 전용 Key를 사용하고, Custom/OpenAI-compatible 서비스에는 [b]신뢰할 수 있는 HTTPS 주소만 사용[/b]하십시오.

[h3]Q. 어떤 문장을 AI에 보내나요?[/h3]

원본 모드, 사용 중인 번역팩, 이전에 저장한 번역을 먼저 확인합니다. 어디에도 번역이 없는 [b]pending 항목만 AI 서비스에 전송합니다.[/b] 모든 문자열을 매번 다시 보내지 않습니다.

[h2]문제 해결[/h2]
[list]
[*][b]Queued[/b] — Helper가 실행 중인지 확인하십시오.
[*][b]No API key is saved[/b] — API Key 입력 후 Apply를 누르십시오.
[*][b]HTTP 401 / 403[/b] — Key와 모델 사용 권한을 확인하십시오.
[*][b]HTTP 429 / 456[/b] — AI 서비스 사용량을 확인하고 나중에 Resume하십시오.
[*][b]Conflicts N[/b] — 여러 모드가 같은 번역 항목을 다르게 사용해 해당 항목이 제외되었습니다.
[*][b]일부 영어가 남음[/b] — 생성 모드 활성화, 번역팩 우선순위, 게임 재시작 여부를 확인하십시오. Lua 하드코딩 문장은 자동 번역 대상이 아닙니다.
[/list]

API 키와 Helper는 창작마당 배포물에 포함되지 않습니다. API Key, 작업 기록과 생성 번역은 사용자 PC에 저장됩니다.

[h2]Helper 종료[/h2]

게임을 종료해도 Helper는 계속 실행될 수 있습니다. 작업이 끝나면 Helper 폴더의 [b]STOP-TranslationHelper.vbs[/b]를 실행하십시오.
